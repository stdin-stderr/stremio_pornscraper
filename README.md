# Stremio PornScraper
A Stremio addon that finds NSFW streams, combine with [stremio_theporndb](https://github.com/stdin-stderr/stremio_theporndb). Currently only supports TorBox.

## Running

```bash
docker compose up
```

**Development** (hot reload, source mounted)
```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up
```
